# Pippotecno
1. Abrí la carpeta en VS Code e instalá la extensión **Live Server**.
2. Firebase (console.firebase.google.com): crear proyecto > Authentication (Email/contraseña) > crear usuario emanuelpratto90@gmail.com > Firestore (modo producción) > pestaña Reglas: pegar `firestore.rules`.
3. Registrar app Web y pegar la configuración en `js/firebase-config.js`.
4. Probar: clic derecho en index.html > Open with Live Server. Admin: admin.html.
5. Subir a GitHub, activar Pages, y agregar `tuusuario.github.io` en Authentication > Configuración > Dominios autorizados.
Primero entrá al admin: creá categorías, cargá el nombre/zona/"Quiénes somos" en Negocio y después tus productos.
